# FinWise

## Орнату
1. Expo жобасына `App.tsx` пен `src/` папкасын көшіріңіз.
2. Пакеттерді орнатыңыз:

    npx expo install @react-navigation/native @react-navigation/native-stack @react-navigation/bottom-tabs react-native-screens react-native-safe-area-context

3. Іске қосыңыз: `npx expo start`

## Ағын
Launch -> Onboarding -> Login -> Main (Home, Transactions, Stats, Profile)

Түстер мен өлшемдер `src/constants/theme.ts` ішінде. Figma-дағы нақты мәндерді осы файлға жазыңыз.
