1Finance App
About the Project

1Finance App is a mobile application project designed to help users manage their personal finances.

Features
Track personal finances
Organize financial information
Simple and user-friendly interface
Technologies Used
React Native
Expo
TypeScript
JavaScript
Getting Started
Installation
Clone the repository:
git clone https://github.com/OralbaiSerzhan/1finance-app.git

Navigate to the project directory:
cd 1finance-app

Install dependencies:
npm install

Start the application:
npx expo start
